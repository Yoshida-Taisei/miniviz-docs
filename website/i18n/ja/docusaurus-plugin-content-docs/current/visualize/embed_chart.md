# グラフを自分のサイトに埋め込む

Visualize の line / bar グラフは、iframe を使って自分のサイトに埋め込めます。

1. Visualize メニューからグラフを開きます。
2. グラフカードの共有アイコンをクリックします。
3. 「サイトへの埋め込みを利用する」をオンにします。
4. **Copy** をクリックして埋め込みコードをコピーします。
5. サイトの HTML にコードを貼り付けます。

![グラフカードの共有アイコン](/images/embed_chart_1.png)

![サイトへの埋め込みを有効にしてコードをコピー](/images/embed_chart_2.png)

## 注意

- 埋め込めるのは  line / bar グラフのみです。(2026/11現在)
- URL を知っている人は誰でもグラフを閲覧できます。共有を止めるには「サイトへの埋め込みを利用する」をオフにしてください。
- オフにしてから再度オンにすると、新しい URL が発行されます。古い URL は使えなくなります。
- 埋め込みグラフはリアルタイム更新されません。最新データはページを再読み込みしてください。`‹` `›` で直近24バケットの表示範囲を移動できます。
- 埋め込み先のページで Content Security Policy を設定している場合は、`frame-src` に `https://miniviz.net` を許可してください。
