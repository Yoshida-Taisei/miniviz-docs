# Introduction

Welcome to the Miniviz documentation!
This site explains how to use Miniviz, a BI platform for easily visualizing and notifying IoT system data.

If you are new here, please check the [Quick Start](./quickstart) first. You can experience data transmission and visualization in as little as 5 minutes.

AI-assisted development? Check out our [AI Quick Start Guide](#ai-quick-start-guide) below.

:::info
This documentation is for the latest version of Miniviz.
:::
